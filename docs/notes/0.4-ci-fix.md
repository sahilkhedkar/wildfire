# CI Fix: Repository TypeScript Toolchain

## Problem

CI installed the workspace with Bun, but the repository did not declare TypeScript. Local typechecks passed only because `tsc` was available outside the workspace; GitHub Actions failed with exit code 127.

## Fix

- Declared stable TypeScript 7.0.2 as a root dev dependency.
- Updated `bun.lock` for frozen installs.
- Added `bun run verify:toolchain`.
- Added the toolchain preflight to CI before Turbo runs.

## Verification

The CI-equivalent local command now passes all 52 uncached Turbo tasks:

```sh
bun install --frozen-lockfile
bun run verify:toolchain
bun run turbo run build typecheck lint test --force
```
