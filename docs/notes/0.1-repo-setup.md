# Batch 0.1: Repository Setup

## Built

- Bun workspace monorepo covering `apps`, `packages`, and benchmark packages.
- Turborepo tasks for build, typecheck, lint, test, and dev.
- Strict shared TypeScript configuration and Biome formatting/linting.
- GitHub Actions checks using Bun and Turborepo.
- Docker Compose PostgreSQL service for later database work.

## Decisions

- Bun 1.4.4 is declared as the package manager because it is installed locally.
- Turbo 2.11.11 uses the current `tasks` configuration key.
- Biome 2.6.7 is used for formatting and linting.
- PostgreSQL is provided by Compose but is not required for the empty skeleton checks.

## Learned

Turborepo coordinates package-level scripts; it does not replace Bun's runtime, package manager, or test runner. Each workspace package must expose the same task names so repository-wide commands remain predictable.
