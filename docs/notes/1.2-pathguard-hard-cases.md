# Batch 1.2: Path Guard Hard Cases

## Built

- Filesystem-aware resolution of existing paths and existing ancestor directories.
- Symlink target checks for reads, writes through symlinked directories, and deletes.
- Repeated percent-decoding checks for encoded and double-encoded traversal.
- Explicit rejection of malformed percent encoding.
- Tests for Unicode lookalikes, Linux case sensitivity, and long lexical paths.

## Decisions

- The guard resolves the nearest existing ancestor so a new file under a symlinked directory is checked against the symlink target.
- Broken symlinks are denied rather than treated as lexical paths.
- Unicode lookalikes and case variants are not rewritten. They remain ordinary filesystem names; case behavior follows the host filesystem.
- Percent encoding is decoded up to three passes for containment checking, preventing double-encoded traversal from bypassing the guard.

## Honest limitation

The synchronous `realpath` check and subsequent filesystem operation still have a TOCTOU window. Phase 2 sandboxing and later descriptor-based or `openat2` hardening are required for stronger guarantees.
