# Batch 1.3: Path Guard Adversarial and Property Tests

## Built

- 50+ handwritten escape cases covering traversal depth, absolute paths, sibling-prefix paths, encoded and double-encoded traversal, null bytes, malformed encoding, and unusual separators.
- Unicode lookalike, case-sensitivity, long-path, and symlink cases from Batch 1.2 remain in the focused suite.
- A `fast-check` property test with 500 generated path strings.

## Property

The property asserts that every `allowed` decision resolves to the workspace root or one of its descendants. Denied inputs may take many forms, but no allowed result may escape the root.

## Decisions

- Property generation is bounded to 500 runs for fast local and CI feedback; the corpus supplies targeted cases that random generation may not discover reliably.
- The property checks the public decision result rather than private helper behavior, so it protects the actual Path Guard contract.
- `fast-check` 4.10.2 is scoped to the Path Guard package as a development dependency.

## Learned

Adversarial tests are useful for examples; properties are useful for the space between examples. Both are needed because a passing attack list cannot prove that a new path shape is safe.
